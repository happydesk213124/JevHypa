# JevHypa

RisuAI용 장기기억 플러그인 (API 3.0).
텍스트 생성 모델 없이 **TypeSafe Jev**(선택·판정 전용 모델)와 임베딩만으로 대화를 대단원 › 장면 › 사건 메모로 쌓고, 필요한 기억만 골라 메인 모델에 넣습니다.

## 설치

1. [`jevhypa.js`](https://raw.githubusercontent.com/happydesk213124/JevHypa/main/jevhypa.js)를 받습니다.
2. RisuAI → 설정 → 플러그인 → 플러그인 추가에서 파일을 고릅니다.
3. 우상단 🧠 버튼을 눌러 시작 안내에 따라 Jev·임베딩 키를 넣습니다.

## 어떻게 기억하나

- **하이파식 (기본):** 최근 2개 메시지만 원문으로 보내고, 그 앞은 전부 기억으로 바꿔요.
  - `<earlier in this scene>`: 지금 장면에서 방금까지의 흐름을 시간순으로 넣어요 (최대 400토큰)
  - 관계 한 줄 + 오래된 기억 회상
  - 아직 정리 안 된 메시지는 원문으로 남기고, 채팅을 열면 뒤에서 자동으로 정리해요
  - 원문을 넉넉히 두고 싶으면 설정 → 모드에서 균형·품질을 고르세요

- **저장 (응답 뒤):** Jev가 문장마다 기억할 가치와 종류를 고르고, 남길 메모에는 카드 칸을 붙여요.
  - 형식: 행동 / 말 / 규칙 / 사실 / 계획 / 소문 / 생각
  - 시점: 현재 / 과거 / 예정
  - 대사가 누구 얘기인지 (남 얘기면 그 사람 메모로)
  - 앞 문장 (무엇에 관한 말인지 모를 때 맥락)
- **회상 (요청 전):** 최신 메시지 중심의 임베딩으로 후보를 모으고, Jev가 0~3점으로 채점해요. 빠진 근거(원인·변화·누가 아는지·구체적 사실)가 있으면 그 목적으로 한 번 더 찾아요.
- **관계 · 지금 상태:** 인물 사이의 관계를 방향별로 쌓아요(A가 B를 어떻게 대하는지).
  - 호칭·존댓말/반말: 대사 줄에서 정규식으로 (무료)
  - 호감·신뢰: 함께 나온 짝마다 Jev가 가까워졌는지·멀어졌는지·믿게 됐는지 골라 ±1씩
  - 관계 종류(친구·연인·라이벌…), 기분, 마지막으로 본 때·곳, 전환점 이력
  - 진행 중인 약속·계획은 지켜지거나 끝나면 Jev가 닫아요
  - 메인 모델에는 지금 장면 사람끼리의 관계만 인물 이름 옆 한 줄로 들어가요. `<하윤> →민준: close, aff +4, calls "민준아", casual`
  - 💞 관계 탭: 관계도와 카드에서 −/+로 바로 고치고, 🔒로 자동 변경을 잠가요
- **번역 (선택):** 메인 모델에 보내기 직전에 메모 줄만 영어로 바꿔요(DeepL / OpenRouter LLM / 구글 무료). 저장된 메모는 한국어 그대로예요.

## 자동 업데이트

파일 머리에 `//@update-url`이 들어 있어서, RisuAI가 이 저장소의 `main` 브랜치에 올라온 새 `//@version`을 감지하면 플러그인 목록에서 업데이트할 수 있습니다.

## JevMemory 2에서 옮겨 올 때

- 기존 **JevMemory 2** 플러그인은 끄거나 지우세요. 둘 다 켜 두면 기억이 두 번 들어갑니다.
- 기억·설정은 같은 저장 키를 쓰므로 그대로 이어집니다.
- 프롬프트의 `[jevmemory]` 자리 표시자도 계속 작동합니다. 새로 쓸 때는 `[jevhypa]`를 쓰면 됩니다.

## 새 버전 올리기 (관리자용)

`jevhypa.js` 4번째 줄의 `//@version`을 올린 뒤 `main`에 푸시하면 됩니다. 버전 줄은 파일 앞 512바이트 안에 있어야 합니다.
